## 分类原则

- **通用**：普通动词、描述词、衔接语、写作短语，以及现有六个专业领域之外的背景词。例如 `substantial`、`with respect to`、`in a nutshell`。这表示已经考虑过其用法，不是“尚未分类”。法律背景词 `bail`、`on parole` 暂作为通用背景词，并在注释中保留语义限制。
- **具体专业**：按术语含义及常见研究用法归类，例如 `tokenization` 属于自然语言处理，`prognosis` 属于医学，`convexity` 属于数学。
- **层级及交叉领域**：机器学习、视觉、NLP 同时可在上位领域“计算机科学”中检索；`voxelwise` 同时涉及视觉与医学，`group lasso` 涉及机器学习和数学。统计/概率相关数学术语并入“数学”，不恢复“统计学”选项。
- **普通词不跟随论文题目分类**：即便 `substantial` 的例句来自视觉论文，它仍是通用表达；不能因此把所有同类词都标为视觉术语。
- **语境不足时保守处理**：`valve` 原译为“阀门”，没有心脏语境；`prime` 原译为“主要的”，没有质数语境。因此两者保留“通用”，不强行推断医学/数学含义。
- **医学含基础生物医学背景**，不另设医学影像与解剖学。对于兼具多种含义的词，标签表示可检索的不同语境，不代表这些含义等同，例如医学与语言模型中的 `hallucinations`。

## 维护方式

1. 修改 `data/domain_annotations.json` 中对应词条的 `domains`，必要时填写 `note`。
2. 运行 `python scripts/migrate_glossary.py`，生成网页 JSON 及新项目初始化用的 SQL。
3. 运行 `python -m unittest discover -s tests -v`。

注释同时保存 ID、英文、释义与词性。原始词项变化时不会静默继承旧标签，也不会自动把未来新词都归“通用”；迁移脚本会提示补充审阅。社区上线后在数据库中维护标签，种子脚本仍只用于初始化。

## 尚未处理的原词表问题

本次不改动词性、拼写或释义。有些词的原释义过泛或可能不准确，例如 `hypointense` 的“低调”、`prognosis` 的“预测”和 `morphism` 的“蜕变”；分类注释中已记录，需要另一步校订。`inference` 仍在原词表的动词部分，也未在本次调整。

部分语义核对参考：[数学中的 Morphism](https://encyclopediaofmath.org/wiki/Morphism)、[Holonomic system](https://encyclopediaofmath.org/wiki/Holonomic_system)。这些资料不是全部 701 条分类的逐项证据；整体标签属于可修订的语义整理结果。
