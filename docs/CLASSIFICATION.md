# 领域标签说明

## 初始词库

初始静态词库的 **701 个词条均已添加领域标签**；以下数量为初始词库统计，不代表当前社区词库规模。词汇、译文、例句和原始四类词性保持不变。

标签依据初始词项、中文释义及可用例句，按常见语义与研究用法整理，**属于语义整理，并非经独立专家验证的分类标准**。每个词条的结果保存在仓库 `data/domain_annotations.json`，可按词条 ID 检查和修订；部分歧义项附有说明。

| 领域 | 词条数 |
| --- | ---: |
| 通用 | 532 |
| 计算机科学 | 130 |
| 医学 | 43 |
| 数学 | 61 |

同一个词可以有多个标签，数量不能相加作为总词数。其中 499 个词条只有“通用”标签，另外 33 个既有通用含义，也有常见的专业用法。

## 分类原则

- **通用**：普通动词、描述词、衔接语、写作短语，以及现有三个专业领域之外的背景词。例如 `substantial`、`with respect to`、`in a nutshell`。这表示已经考虑过其用法，不是“尚未分类”。法律背景词 `bail`、`on parole` 暂作为通用背景词，并在注释中保留语义限制。
- **具体专业**：按术语含义及常见研究用法归类，例如 `tokenization` 属于计算机科学，`prognosis` 属于医学，`convexity` 属于数学。
- **层级及交叉领域**：机器学习、计算机视觉、自然语言处理统一归入“计算机科学”，不再作为独立标签；已有词条转换后去重，保留其他领域。`voxelwise` 同时涉及计算机科学与医学，`group lasso` 涉及计算机科学和数学。统计/概率相关数学术语并入“数学”，不恢复“统计学”选项。
- **普通词不跟随论文题目分类**：即便 `substantial` 的例句来自视觉论文，它仍是通用表达；不能因此把所有同类词都标为视觉术语。
- **语境不足时保守处理**：`valve` 原译为“阀门”，没有心脏语境；`prime` 原译为“主要的”，没有质数语境。因此两者保留“通用”，不强行推断医学/数学含义。
- **医学含基础生物医学背景**，不另设医学影像与解剖学。对于兼具多种含义的词，标签表示可检索的不同语境，不代表这些含义等同，例如医学与语言模型中的 `hallucinations`。

## 维护方式

修订对应词条的 `domains`，歧义处填写 `note`。注释绑定 ID、英文、释义与词性；原词项变化后需重新审阅，不会自动归为“通用”。生成与验证步骤见[维护指南](MAINTENANCE.md#数据来源与生成)。社区词条通过网站维护；已有数据库合并标签见[部署指南](DEPLOYMENT.md#领域标签合并)。

## 待校订内容

分类调整不改动词性、拼写或释义。有些词的原释义过泛或可能不准确，例如 `hypointense` 的“低调”、`prognosis` 的“预测”和 `morphism` 的“蜕变”；分类注释中已记录，需要另一步校订。`inference` 仍在原词表的动词部分，仍待校订。

部分语义核对参考：[数学中的 Morphism](https://encyclopediaofmath.org/wiki/Morphism)、[Holonomic system](https://encyclopediaofmath.org/wiki/Holonomic_system)。这些资料不是全部 701 条分类的逐项证据；整体标签属于可修订的语义整理结果。
