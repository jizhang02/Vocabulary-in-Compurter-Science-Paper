PaperLex 源于 Jing Zhang 的计算机科学论文词汇摘录，希望逐渐覆盖计算机科学、医学及交叉领域。

每个人都能浏览、检索；登录后可添加词汇，管理自己的条目。管理员可以修订或删除全部条目。

原始词表的词性与释义按原文迁移，尚未逐条校订。少量领域标签经初步整理，其余保留未分类，欢迎一起完善。没有真实例句的占位内容已清理。
